# AI 回答协议

所有业务 Agent 必须按以下顺序处理和输出结果：

1. **Claim（主张）**：把回答拆成可独立验证的事实或建议，并给出置信度。
2. **Citation（引用）**：每个游戏事实关联检索来源，包含标题、来源、片段、版本和更新时间。
3. **Validation（验证）**：检查引用是否真正支持主张，标记已验证、部分验证、未验证或冲突。
4. **Filtering（过滤）**：移除无证据事实、低相关内容、重复内容、过期冲突内容和不安全内容。

推荐或分析可以包含推理，但必须与游戏事实分开。没有可靠证据时明确表示未知。
材料数量、掉落位置等精确数据优先使用结构化数据库验证。
