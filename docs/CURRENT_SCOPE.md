# 当前版本范围说明

本文说明毕业设计当前版本主动确定的实现边界。这些内容是“暂不纳入本次计划”，不应表述为项目资料缺失或功能失败。

## 已完成的数据范围

- 角色养成材料绑定覆盖角色图鉴当前展示的全部角色。
- 角色数量不在文档中作为固定完成标准；图鉴新增或移除角色后，应重新运行 `backend/scripts/build_progression_data.py` 生成绑定与审计结果。
- 审计文件中的 `character_count` 和 `complete_count` 是生成当时的数量快照，是否完成应以 `issue_count` 和图鉴覆盖关系为准。
- 光锥、遗器、物品、剧情、活动与配队数据均按当前产品页面和 Agent 实际使用范围维护。

## 当前版本暂不计划实现

- 完整可点击行迹树，包括节点名称、前置关系、解锁条件与逐节点材料交互。
- 地图、宝箱、锚点、谜题和导航坐标功能。
- 通用 Boss 与全部副本攻略；攻略模块当前聚焦 4.4 活动。
- 往期活动的完整攻略、结构化前置任务、奖励与精确起止时间；往期活动仅作为档案浏览。
- 实时副本状态及确定掉落数量预测；每周规划使用现有材料绑定与固定体力成本。
- AI 立绘、图片上传、语音、评论、点赞和举报等社区扩展功能。

上述范围可以作为后续版本扩展方向，但不计入本次毕业设计的未完成缺陷。
