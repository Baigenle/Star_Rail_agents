# 40_canon.md —— 剧情口径校准（2 条，持续增长型）

## 版本剧情节点口径表
- 触发词: 剧情讲到哪, 剧情讲到哪里, 版本剧情, 主线进度, 最新剧情是什么, 4.4, 二相乐园, 归寂, 剧情年表, 开拓者已死, 行走的记忆, 幻月游戏, 死了是真的吗
- 常驻: 否
- 内在价值: 85
- 优先级: 90
- 连带触发词: 翁法罗斯, 黄金裔, 匹诺康尼, 假面愚者

【事实】当前版本：**4.4「鸣笛于归寂之时」**（用户口径基线，2026-09）。四时代骨架：
1.x「银河启程」——空间站/雅利洛/仙舟罗浮；1.2 假"停云"现身为绝灭大君幻胧，丹恒显现饮月君真身；
2.x「匹诺康尼的梦境」——流萤与知更鸟的"死亡"之谜，美梦由星核驱动、家族信仰已陨落的"秩序"（2.2），打破星期日的"太一之梦"，2.7 收到翁法罗斯线索；
3.x「翁法罗斯的英雄纪」——黄金裔逐火之旅；3.2 揭示开拓者早已死亡、玩家操控的是"行走的记忆"；3.4 揭示翁法罗斯为永劫回归的轮回；3.7 主线完结，文明以"记忆"形式保存；
4.x「欢愉与神座」——「欢愉」命途新主线"二相乐园"（乐子神阿哈的幻月游戏），4.4 终局揭示"归寂"（原假面愚者、前列车领航员）的真相，与姬子的过去紧密相连。
完整逐版本年表已收录知识库（"版本剧情年表"），长尾细节用 knowledge_search 现查。
【写法】被问"剧情讲到哪"：先报当前版本与所处时代，再反问用户玩到哪，**避免剧透未达节点**；报节点时带"更新于"标记；用户聊到未达节点的剧情时提醒一句"涉及你还没玩到的部分"。
【口径】以上全部为官方盖章剧情；3.2"开拓者已死"、3.4"永劫回归"是官方设定不是脑洞，用户拿它们玩梗时正常接。社区推论（角色关系、转世说等）不得当事实陈述。

## 高频考据易错点校准
- 触发词: 黑塔是人偶吗, 大黑塔是谁, 黑塔女士和黑塔, 俱乐部编号, 几号天才
- 常驻: 否
- 内在价值: 85
- 优先级: 95
- 连带触发词: 人偶, 本体, 天才俱乐部

【事实】起步四条（随用户实际问错的问题持续追加）：①「黑塔是人偶还是本体」——分阶段：日常多为远程人偶 [content_49]；4.x 起本体（大黑塔）已亲自现身 [1401 实装]，两阶段口径不可混用。②「大黑塔是另一个角色吗」——不是，是同一人的本体形态/称呼变体（见 00_glossary 称谓映射）。③「天才俱乐部编号」——#83 黑塔、#81 阮·梅有据，其余编号无据，禁止即兴给号。④「站长是谁」——空间站站长是艾丝妲，黑塔是命名者与真正主人，别混。
【写法】纠正用户时用"档案修正"姿态，别用"你错了"开头——本天才修正的是档案，不是人。
【口径】本条每一条都必须有 docs 出处；新增易错点由 40_canon 维护流程追加（上线后收集用户实际问错的问题）。
