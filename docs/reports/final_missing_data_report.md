原始角色 Markdown 中共有 1771 个 `行迹 point` 标题，但对应内容为空。要实现可点击行迹树，仍需补充：

- 节点唯一 ID 和正式名称。
- 节点类型：小属性、额外能力、技能等级或专属节点。
