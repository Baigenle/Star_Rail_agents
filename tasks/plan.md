# 毕业设计系统验收与文档完善计划

## 目标

对当前前后端、Multi-Agent、RAG、用户数据、社区审核与部署链路做一次可复现验收，补齐测试空白、必要中文注释和启动文档。

## 阶段

1. 盘点 FastAPI 接口、Vue 路由、现有测试及管理员鉴权方式。
2. 为注册、登录、Token、管理员授权和核心 OpenAPI 契约补充自动化测试。
3. 修复验收中发现的问题，并只在复杂边界处添加解释“为什么”的中文注释。
4. 重写 README 的安装、Docker/PyCharm 启动、数据初始化、管理员配置与故障排查章节。
5. 执行 Pytest、Ruff、Vue 类型检查与生产构建、依赖审计、Docker 健康检查和真实浏览器验收。
6. 输出验收报告，区分“已通过”“部分可用”和“受资料限制”的功能。

## 验收标准

- 后端完整测试集通过，新增鉴权与管理员边界测试。
- 前端 TypeScript 检查和生产构建通过。
- Docker Compose 配置有效，核心容器健康，主要网站与 API 可访问。
- 普通用户无法进入管理员 API；配置的管理员用户名可以进入。
- README 能让一台具备 Docker Desktop 和 PyCharm 的 Windows 电脑从零启动项目。
- 不在日志、文档或测试中泄露真实 API Key、密码或 Token。
